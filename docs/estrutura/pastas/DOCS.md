# `docs/` — Documentação técnica

Documentação profissional do projeto, separada do código-fonte.

## Inventário

| Arquivo / Pasta | Função |
|-----------------|--------|
| `README.md` | Índice central da documentação |
| `auditoria/AUDITORIA-COMPLETA.md` | Relatório SEO, UX/UI, a11y, performance |
| `estrutura/MAPA-PROJETO.md` | Visão geral da árvore e convenções |
| `estrutura/ECOSSISTEMA.md` | Pastas externas ao repositório |
| `estrutura/pastas/` | Inventário arquivo a arquivo por diretório |
| `estrutura/pastas/RAIZ.md` | Arquivos na raiz do repo |
| `estrutura/pastas/SRC.md` | Código-fonte em `src/` |
| `estrutura/pastas/PUBLIC.md` | Assets estáticos |
| `estrutura/pastas/DOCS.md` | Este arquivo |
| `estrutura/pastas/SCRIPTS.md` | Scripts de automação |
| `estrutura/pastas/GITHUB.md` | CI/CD |
| `plano/PLANO-ACAO.md` | Backlog priorizado e cronograma |

## Manutenção

1. Mudança de estrutura → atualizar `MAPA-PROJETO.md` e pasta em `pastas/`
2. Release significativa → revisar `AUDITORIA-COMPLETA.md`
3. Item concluído → marcar em `PLANO-ACAO.md`
